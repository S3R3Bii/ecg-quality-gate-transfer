# Study 39: Test a signal-quality gate on another recording

## Decision and acceptance

Can two inexpensive, explicitly defined waveform checks detect added electrode-motion noise on a separate ECG recording without rejecting too many source-clean windows? Deliver a bounded signal-processing benchmark, complete retained threshold search, a separate-recording evaluation, an implementation exercise, three original figures and a reviewed independent manuscript. The historical proposal concerned confident prediction errors and recording devices. This narrower study evaluates the quality gate itself; it contains no downstream clinical predictor, actual device comparison, arrhythmia correctness, patient outcome or operational safety claim.

Acceptance requires openly accessible exact source files and attribution, original hashes and native header/checksum verification, independent waveform decoding, fixed complete windows, recording separation, retained candidate/selection evidence, committed dependencies before any recording119 feature or performance output, independent metrics/selection checks, source-preserving replay, bounded meaningful fixtures, visually reviewed figures and every paper page, canonical privacy/manuscript scope audit, exact candidate/main CI, matching tested content, remote annotated tag and accurate catalog metadata. Criteria are source/privacy, numerical correctness, separation/selection, reproducibility and clear practical presentation. Each applicable gate must pass; 4/5 means these specified checks pass, never clinical validation or universal correctness. At most three substantive review rounds, 45 active review minutes and 60 review-specific tool calls; preserve failures and report unavailable accounting honestly.

## Authored feature definitions and finite search

For each3600-sample physical-mV window x, center z=x-mean(x) and define V=mean(z^2). Reject invalid/nonfinite, wrong-length or flat V=0 input as unavailable; never make an invalid waveform a clean observation. Define slope-energy ratio H=mean((x[i+1]-x[i])^2)/V over3599 differences. Define baseline-block ratio B=mean((mean(x over each of ten disjoint360-sample one-second blocks)-mean(x))^2)/V. Both are dimensionless. The one-second blocks and10-second windows are fixed interpretable engineering choices, not fitted frequency cutoffs or validated clinical indices. Neither requires annotations, labels, a clean counterpart, training-set normalization or future samples outside the current window at inference. A larger B measures slow block-mean variation; a larger H measures rapid adjacent changes. Their limitations, including insensitivity to certain motion patterns and physiology changes, remain explicit.

Threshold candidates are p in{0.90,0.95,0.99}. For each feature, its threshold is the nearest-rank p quantile of the30 source-clean118 calibration windows: sorted element ceil(p*30)-1. Flag a window when either B or H is strictly above its corresponding threshold. No lower bounds, smoothing, resampling, selected channels, feature search, random seeds, probabilities or ML are used. Retain all three thresholds and full development predictions. The baseline accepts all finite valid windows. Select the nonbaseline candidate with source-clean development false-rejection fraction<=0.05 and maximum pooled -6/0/6dB detection fraction; ties prefer larger p. If none is feasible select accept-all. The5% constraint and severity grouping are authored demonstration assumptions, without measured clinical cost or empirical service requirement. No search expansion is permitted. Boundary winners are finite-grid selections, not global optima.

Report all confusion counts, prevalence, precision when defined, recall, specificity, false-rejection rate and balanced accuracy for each development candidate and the baseline; unidentifiable precision when no window is flagged stays unavailable. Export each observation and decision. The primary later comparison is frozen selection versus accept-all on recording119. Give lower-SNR detection separately for each of -6/0/6dB and secondary12/18/24 strata, plus clean false rejections. A quality rejection means manual review/reacquisition would be considered in this exercise; it is never an instruction to suppress clinical alarms.

## Authored sensitivity and implementation exercise

On development and, after freeze, later windows, apply the same frozen thresholds to two specified transformations: gain/offset y=2*x+0.5mV, and quantization y=0.02*round(x/0.02)mV using ties-to-even. Gain/offset should preserve both features and decisions within floating-point tolerance; this is an algebraic invariant check. Quantization can change features/decisions; report every flip and subgroup, without retuning. These are authored numerical changes, not recordings from another device, device robustness or calibration certification. Do not resample or choose a quantization step after observing performance.

Provide an offline CLI for a3600-sample10-second mV window using the frozen rule, with clear finite/flat/length guards and reason fields. Demonstration windows must be authored waveforms, never published source traces or invented patients. Return a demonstration flag or unavailable state without clinical advice. Include a worked exercise about why copying windows across records or counting repeated clean SNR variants inflates evidence.
